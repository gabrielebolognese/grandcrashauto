# Credits

**Coastline** (working title) is an original game. The city, cars, characters, brands, UI and sounds are all original
and **generated in code at runtime** — the repository ships no third-party art, models, textures, fonts or audio files.

## Third-party software

| Package | Use | Licence |
|---|---|---|
| [three.js](https://threejs.org/) (`three`) incl. `examples/jsm` add-ons (EffectComposer, UnrealBloomPass, OutputPass, RoomEnvironment, BufferGeometryUtils) | WebGL2 rendering | MIT |
| [Rapier](https://rapier.rs/) (`@dimforge/rapier3d-compat`) | Physics, raycast vehicle controller | Apache-2.0 |
| [Vite](https://vite.dev/) | Dev server and bundler (build-time only) | MIT |
| [TypeScript](https://www.typescriptlang.org/) | Language and type checking (build-time only) | Apache-2.0 |
| [Playwright](https://playwright.dev/) | Headless smoke tests (dev-only, not shipped) | Apache-2.0 |

## Third-party assets

None. Every 3D model (cars, buildings, props, pedestrians), texture (facades, road markings, licence plates, particle
sprites), animation and sound effect is procedurally generated by the game's source code.

Fonts: the UI uses the device's system font stack (no web fonts are downloaded).
